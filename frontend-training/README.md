# 前端设计能力训练（Frontend Design Training）

> 通过真实题目、视觉先行、浏览器实测和用户批评，持续提高 AI 的产品理解、界面审美、交互设计与前端工程能力。

## 训练目标

本训练不是单纯练习生成 HTML/CSS，而是建立可复验的设计与实现能力。每轮都必须有明确题目、设计稿、实现、真实运行证据、用户评价和提示词改进记录。

## 不可跳过的训练闭环

1. **接收题目**：复述目标用户、核心任务、使用场景、约束和成功标准；不擅自扩大需求。
2. **设计研究**：分析同类产品与优秀案例，提炼适合本题的布局、信息层级、交互模式和视觉语言。外部研究结论必须有来源；无法核实时标注为经验判断。
3. **先出效果图**：先生成高保真视觉效果图，必要时提供关键页面或状态，不先写页面代码。
4. **设计审查**：向出题者展示效果图、设计理由、关键交互和待确认假设。根据反馈修订；未获认可前不进入正式实现。
5. **前端实现**：按批准的设计实现页面，优先保证核心流程真实可用，不用静态装饰冒充功能。
6. **真实验收**：启动项目，在真实浏览器中检查桌面和移动端；检查布局、交互、键盘操作、可访问性、控制台和网络错误。
7. **截图交付**：分别保存效果图与真实运行截图。效果图不能冒充运行截图，代码截图不能替代浏览器证据。
8. **用户批评**：完整保留出题者的原始评价，不擅自改写成更温和的表述。
9. **根因分析**：把问题归类为需求理解、产品结构、视觉层级、排版、色彩、交互、响应式、工程实现或验收遗漏，并说明证据。
10. **提示词进化**：只把经过证据支持、可迁移的经验写入下一版提示词；保留旧版本和差异。
11. **回归复核**：确认修复有效且没有破坏已通过的内容，更新本轮状态。

**硬门槛：每轮先生成效果图；设计未确认，不提前编码。**

## 目录约定

- `DESIGN_PRINCIPLES.md`：长期设计原则与反模式。
- `PROMPT_V1.md`：主提示词基线。
- `evaluation-rubric.md`：统一评分标准与验收门槛。
- `prompts/`：可组合的阶段提示词。
- `templates/ROUND_TEMPLATE.md`：每轮记录模板。
- `training-log.md`：训练总索引，不覆盖历史。
- `iterations/round-NNN/`：每轮题目、设计说明、批评、根因、提示词差异与验证结果。
- `screenshots/round-NNN/`：效果图与真实浏览器截图。

## 证据和截图规则

每轮至少区分以下证据：

| 证据 | 说明 | 能证明什么 |
|---|---|---|
| Design Mockup | 生成的视觉效果图 | 设计意图与视觉方案 |
| Browser Screenshot | 页面实际运行截图 | 指定提交和环境下的实际渲染 |
| Test Result | 测试命令、结果、日志 | 被覆盖的功能行为 |
| Console / Network | 浏览器控制台和网络记录 | 前端运行错误与请求状态 |
| Git Commit | 代码提交 SHA | 被验证的代码版本 |

截图命名建议：

- `design-mockup-v1.png`
- `design-mockup-v2.png`
- `desktop-1440x900.png`
- `tablet-1024x768.png`
- `mobile-390x844.png`

每张运行截图都要在记录中注明 commit SHA、浏览器、视口尺寸、设备像素比和采集时间。无法真实运行或无法采集截图时，明确标记为未验证，不得伪造证据。

## 训练状态定义

- `PLANNED`：题目已记录，尚未开始。
- `DESIGNING`：研究或效果图制作中。
- `AWAITING_DESIGN_REVIEW`：等待出题者审查设计。
- `IMPLEMENTING`：按已确认设计实现。
- `VERIFYING`：正在进行浏览器和功能验收。
- `AWAITING_CRITIQUE`：已交付截图，等待出题者评价。
- `REVISING_PROMPT`：正在分析批评并修改提示词。
- `PASSED`：满足本轮验收门槛，且证据齐全。
- `BLOCKED`：存在明确阻塞，记录原因和可继续推进的部分。

## 训练原则

- 不把主观审美包装成客观事实；评分必须附具体证据。
- 不以代码量、组件数量或动画数量代表质量。
- 不为了视觉效果牺牲可读性、可用性、性能和无障碍。
- 不用默认模板堆砌卡片、渐变、阴影和玻璃拟态。
- 不把计划实现、静态原型和真实验证混为一谈。
- 每轮保留失败、修改和负面结果，不能只保留最终成果。
- 设计原则可以演进，但旧版提示词和历史记录不可覆盖。
