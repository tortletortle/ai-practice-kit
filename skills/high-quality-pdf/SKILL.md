# 高质量 PDF 制作

质量优先于速度。按「内容校对 → 版面设计 → 导出 → 逐页验收 → 修订复验」完成交付。优先遵循当前任务明确指定的受众、内容范围、尺寸和风格。

按交付类型使用 [逐页验收细则](references/pdf-review.md)。其中包含中文码点排查和验收记录模板。

## 核对内容

- 列出交付范围、阅读顺序和每页职责。忠实保留用户材料的事实与术语。核对关键定义、公式适用条件、变量、单位、推导和例题结果。对高风险计算独立复算或代入典型值与边界值。查证需要外部依据的陈述，并在成品中按需标注来源与假设。
- 根据原始数据核对图表的绘图点、轴单位、刻度、范围、图例和正文引用。确保示意图的箭头、连接关系与文字一致。用数据绘图工具生成精确图表，优先保留矢量路径和可选中文本。

## 设计与生成

- 按用途选版型。教材通常用纵版，宽图或思维导图可用横版。建立标题、正文、图注和标注的层级，统一页边距、对齐和强调色。先拆页、改标签或调整布局，再考虑缩小字号。A4 可从中文正文 11–12 pt、图注和节点标签 10 pt 起排，以实际尺寸验收。
- 先试排一小页，放入中文常用字与罕见字、各字体字重、中文标点、公式和图注。选可嵌入且覆盖所需字形的简体中文字体，如 Noto Serif CJK SC 或 Noto Sans CJK SC。复杂数学优先用 XeLaTeX 配合 xeCJK 或经过实测的数学排版引擎。使用浏览器打印时，等待字体与公式渲染完成，再按打印样式导出。
- 保持公式上下标、分式、根号、括号和符号的层级。检查中文换行、孤立小标题、跨页表头、公式断行和图注与图形配对。确保图例和连线标签在阅读尺寸下清楚，颜色之外可用线型或文字区分类别。

## 思维导图

- 默认交付多页 PDF。第 1 页从主题节点展开，覆盖全部主要分支及各分支的关键子主题，呈现整体知识结构。总览页直接从图开始，封面或说明可并入总览。
- 从第 2 页起按总览顺序展开主要分支。沿用分支的名称、颜色和标识。分支过密时继续拆页并标注续页。总览可标出分支页码，方便定位。
- 检查每个分支都有对应展开页，图中层级清晰、标签完整，连线避开文字。按正常阅读比例检查最密集区域。用户需要时可附图片预览，同时提供 PDF。

## 验收最终 PDF

1. 从即将交付的 PDF 渲染全部页面。例如用 `pdftoppm -r 150 -png final.pdf review/page`，先创建输出目录。可用 PyMuPDF 作为替代。用 `pdfinfo` 或 PDF 库确认 PDF 能打开且渲染页数匹配。
2. 按页打开实际渲染图。先看整页构图、边距、顺序和裁切，再放大看中文、公式、坐标轴、图例、节点和表格。重点排查缺字、乱码、变形、遮挡、越界、错误连线和页码。逐页记下检查结果与修复项，可用缩略图定位问题，并在单页图上确认。
3. 对可选中文本，用 `pdffonts` 检查所用字体的嵌入情况，用 `pdftotext` 抽查中文是否可搜索、复制，并比对源文字。字符提取和画面渲染分别检查。遇到字体类型或字形映射警告时，用第二个 PDF 渲染器复核，优先更换字体或导出路径后重试。中文兼容字可用 Unicode 规范化辅助定位，仍要核对原字是否可正确搜索与复制。确认存在的目录链接、交叉引用和书签指向正确。
4. 修复后重新导出最终文件并逐页复查，尤其留意改动导致的分页变化。交付验收通过的 PDF。若技术条件确实阻塞检查，明确说明尚未验证的页面或项目，准确报告完成状态。
